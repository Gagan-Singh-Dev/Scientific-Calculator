# 🧮 Scientific Calculator Web App  

A modern **scientific calculator** built using **HTML, CSS, and JavaScript** 💻.  
Designed with a sleek **glassmorphism UI** ✨ and fully responsive layout 📱, this app delivers powerful calculations with a smooth and intuitive user experience ⚡.  

---

## 🚀 Features  

- 🧠 Advanced calculations (Trigonometry, Logarithms, etc.)  
- 🔁 DEG/RAD mode switching  
- ⚡ Real-time calculations  
- 🎨 Glassmorphism UI design  
- 📱 Fully responsive layout  
- ⌨️ Clean and user-friendly interface  

---

## 🛠️ Tech Stack  

- HTML5  
- CSS3  
- JavaScript (ES6)
